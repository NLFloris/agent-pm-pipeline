# Results

Everything here is written by a script in `experiments/` (see
`experiments/README.md` for the command per file), except the raw recordings
of agent runs and the raw Judge responses, which came from a model endpoint
and are kept because they cannot be regenerated byte for byte.

## Reports

| file | what it is |
|---|---|
| `VALIDATION.md` | the validation round of 23 to 26 October 2026: 15 agents per domain, the retail domain, a second Judge, the endpoint's response cache. Read this first. |
| `RESULTS.md` | the running lab report from 1 October 2026 onwards, with dated corrections. Where it disagrees with `VALIDATION.md` or the thesis, those are later and win. |

## By corpus

| corpus | raw runs | outputs |
|---|---|---|
| τ²-bench airline, Claude Opus 4.5, 200 runs | not here: `examples/demos/tau2_airline/`, or the full mirror | `logs/`, `ocel/tau2_airline*.ocel.json`, `task_type_conformance.json`, `task_type_details.txt`, `partial_order.txt`, `pm4py/`, `judge/` |
| τ²-bench retail, Claude Opus 4.5, 448 scorable runs | not here: the full mirror | `task_type_conformance_retail.json`, `judge/retail/` |
| τ²-bench, 15 other agents per domain | not here: the full mirror | `cross_agent.txt`, `cross_agent.json` |
| AgentHallu, Magentic-One, 94 runs | not here: `examples/demos/agenthallu_magentic_one/` | `ocel/agenthallu_magentic.ocel.json`, `figures/agenthallu_magentic_*`, `three_corpora.txt` |
| harness, first recording, 8 runs (13 October 2026) | `local/` | `ocel/local_magentic.ocel.json`, `figures/local_*`, `pm4py/local_magentic_*` |
| harness, OpenTelemetry recording of the same 8 tasks (19 October 2026) | `local_otel_live/` (harness), `otel_live/capture.jsonl` (spans) | `otel_live/` (report), `ocel/otel_live.ocel.json` |
| harness, sub-agents, 10 `claim_check` runs (26 October 2026) | `local_subagents/runs/` | `local_subagents/conformance.txt`, `local_subagents/report/`, `ocel/local_subagents.ocel.json`, `figures/thesis/subagent_lanes.pdf` |

| Claude Code and AutoGen OpenTelemetry probes | `otel_probe/` | `otel_probe/claude_code_capture.txt` |

The harness runs used gpt-oss:120b on the BFH inference endpoint.

TraceElephant and AgentHallu's Camel subset were explored and then set aside
for the thesis. Their outputs (`ocel/te_*`, `figures/te_*`,
`figures/agenthallu_camel_*`, `pm4py/te_magentic_*` and parts of
`three_corpora.txt`) stay because the scripts still produce them when the data
is present.

## Folders

| folder | contents |
|---|---|
| `frozen/` | sha256 of the reference models that were fixed before any run was scored against them |
| `judge/` | per Judge model and condition: `raw_*.jsonl` (every prompt and response), `verdicts_*.json`, and the comparisons `evaluation.txt`, `evaluation_per_type.txt`, `two_judges.txt`; `retail/` and `self_agreement/` the same for the retail domain and the repeat runs; `archive/` the output-only verdicts before their rerun of 21 October 2026 |
| `logs/` | the τ²-bench airline log flat, as CSV and XES, and the verdict per run |
| `ocel/` | one OCEL 2.0 log per corpus; `BUILD.txt` is what the build printed |
| `figures/` | the pipeline's pictures as PNG; `thesis/` the vector figures the thesis prints |
| `pm4py/` | pm4py's own discovery and conformance, the noise sweep and its hash-seed check |
