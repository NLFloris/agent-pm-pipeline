# Results

Everything here is written by a script in `experiments/` (see
`experiments/README.md` for the command per file), except the raw recordings
of agent runs and the raw Judge responses, which came from a model endpoint
and are kept because they cannot be regenerated byte for byte. Where a dated
report below disagrees with the thesis, the thesis has the final numbers.

The data in this folder is licensed CC BY 4.0, apart from the third-party material
inside it, which keeps its own licence; `LICENSE.md` says which.

## Reports

| file | what it is |
|---|---|
| `VALIDATION.md` | the validation round of 23 to 26 October 2026: 15 agents per domain, the retail domain, a second Judge, the endpoint's response cache. A dated working report. |
| `RESULTS.md` | the running lab report from 1 October 2026 onwards, with dated corrections. Where it disagrees with `VALIDATION.md` or the thesis, those are later and win. |

The harness runs used gpt-oss:120b on the BFH inference endpoint.

TraceElephant and AgentHallu's Camel subset were explored and then set aside
for the thesis. Their outputs (`ocel/te_*`, `figures/te_*`,
`figures/agenthallu_camel_*`, `pm4py/te_magentic_*` and parts of
`three_corpora.txt`) stay because the scripts still produce them when the data
is present. They are derived from data under CC BY 4.0: M. Chen, J. Wang, F. Mu,
Y. Wang, Z. Liu, H. Feng and Q. Wang, *Seeing the Whole Elephant: A Benchmark
for Failure Attribution in LLM-based Multi-Agent Systems*, ACL 2026
([TraceElephant](https://huggingface.co/datasets/TraceElephant/TraceElephant)),
and the AgentHallu work cited in `examples/demos/README.md`.

## Folders

| folder | contents |
|---|---|
| `frozen/` | sha256 of the reference models that were fixed before any run was scored against them |
| `judge/` | per Judge model and condition: `raw_*.jsonl` (every prompt and response), `verdicts_*.json`, and the comparisons `evaluation.txt`, `evaluation_per_type.txt`, `two_judges.txt`; `retail/` and `self_agreement/` the same for the retail domain and the repeat runs (glm-5.3-flash's repeat run was stopped after 3 of the 30 runs and is not used); `archive/` the output-only verdicts before their rerun of 21 October 2026 |
| `logs/` | the τ²-bench airline log flat, as CSV and XES, and the verdict per run |
| `ocel/` | one OCEL 2.0 log per corpus; `BUILD.txt` is what the build printed |
| `figures/` | the pipeline's pictures as PNG; `thesis/` the vector figures the thesis prints |
| `pm4py/` | pm4py's own discovery and conformance, the noise sweep and its hash-seed check |
