--- l05_fix_bug final answer, 43.7s, error None
The `growth` function in **calc.py** now checks for a zero divisor before performing the division, preventing a `ZeroDivisionError`.

### Updated `calc.py`
```python
def revenue(units, price):
    return units * price


def growth(a, b):
    """Return percent change from a to b.
    Handles the case where a is zero by returning 0 (or could return
    appropriate value such as float('inf')). Here we return 0 to avoid
    division by zero.
    """
    if a == 0:
        # If both a and b are zero, change is zero; otherwise define as 0
        return 0
    return (b - a) / a
```
